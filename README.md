# Bilice Kebap — демосайт

Лёгкий статический сайт на турецком языке. Концепт для предложения владельцу, не официальный сайт ресторана. Без бронирования, оплаты и сбора данных.

## Файлы

- `content.json` — название, контакты, ссылки, весь основной текст, подписи и пути к изображениям.
- `style.css` — дизайн и адаптивность.
- `build.mjs` — генератор HTML и JavaScript, не требует npm-зависимостей.
- `dist/` — полностью готовый сайт для любого статического хостинга.
- `dist/assets/` — пять изображений WebP и отдельное мобильное кадрирование.
- `IMAGE_PROMPTS.md`, `IMAGE_PROMPTS_V2.md` — промпты встроенного image_gen и происхождение изображений.
- `qa/` — скриншоты проверки.

## Изменить и запустить

1. Измените `content.json` и при необходимости `style.css`.
2. Выполните `node build.mjs` из папки проекта (Node.js 22 или новее).
3. Запустите `python -m http.server 4173 --directory dist`.
4. Откройте `http://localhost:4173`.

Для другого заведения также замените монограмму в генераторе favicon и координаты SVG-подсветки под новое фото. `dist/index.html` можно открыть напрямую без сервера; для публикации загрузите всё содержимое `dist/`.

## Публикация

Сборка не требует серверного кода. В Cloudflare Pages используйте Direct Upload папки `dist`, либо перетащите её в Netlify Drop. Если хостинг запрашивает build command: `node build.mjs`, output directory: `dist`. Инструкции провайдеров: https://developers.cloudflare.com/pages/get-started/direct-upload/ и https://docs.netlify.com/deploy/create-deploys/ .

Не загружайте `.git`, `.openai`, `qa` или служебные исходники в корень публичного сайта. Для переноса в другой проект Sites не используйте существующий project_id.

Установлены meta robots noindex,nofollow, robots.txt и X-Robots-Tag для хостингов, поддерживающих `_headers`. Noindex не ограничивает доступ по ссылке.

## Изображения и контент

Изображения созданы встроенным image_gen по описанию из задания: пять фото-референсов не были приложены в этом чате. Это иллюстративная сервировка; на сайте есть подпись `Görseller temsilidir.`. В меню нет неподтверждённых цен или названий блюд. Контакты взяты из задания; ссылка Google Maps проверена переходом на Bilice Kebap.

Шрифт Poppins загружается через Google Fonts; при недоступности используется Arial. Остальные ресурсы локальные. Вторая версия следует композиции Betro: большой центральный кадр, боковые фотографии, светлый фон и плотная типографика. Интерактивные кнопки находятся под основным подносом. Повторный поднос убран; добавлена мобильная навигация.

## Проверка

В браузере проверены ширины 390 и 1440 px, отсутствие горизонтального переполнения, загрузка изображений, якорная навигация и переключение Kebap / Meze / Lavaş мышью и клавишами Enter/Space. Ссылка звонка проверяется как `tel:+905320596712`; настоящий звонок не выполняется.

## Водяной знак

На всю страницу наложена полупрозрачная подпись `Bilice Kebap · Design concept by David` через `watermark.svg`. Та же подпись встроена в каждый WebP-файл внутри `dist/assets/`, поэтому она сохраняется при скачивании отдельных изображений. Водяной знак обозначает демонстрационный дизайн; он не является технической защитой от копирования кода.
